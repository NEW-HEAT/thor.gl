# Atlas data

`countries.geojson` is derived from Natural Earth's 1:50 million Admin 0 countries.
Coordinates are rounded to four decimal places; only country names, codes, label
positions and label ranks are retained. Downloaded September 10, 2026.

Source: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_50m_admin_0_countries.geojson

Natural Earth data is public domain: https://www.naturalearthdata.com/about/terms-of-use/

The atlas depicts country outlines and coastlines. It is not a street map.
